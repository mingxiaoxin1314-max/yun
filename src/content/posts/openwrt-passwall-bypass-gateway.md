随着家庭网络设备激增，iPhone、iPad、Mac、Windows、Apple TV 4K、电视盒子、Switch、PS5、智能音箱等设备如果每台都单独安装配置代理客户端，不仅维护订阅极其繁琐，且游戏主机与电视盒子通常根本不支持安装客户端。

通过在家庭局域网部署一台低功耗迷你主机（或工控机）安装 **OpenWrt / iStoreOS**，配置为 **旁路由（Bypass Gateway）**，即可实现全屋设备自动透明代理分流：国内流量直连高速走主路由，国外流量自动走机场专线。

---

## 一、网络拓扑与硬件准备

### 推荐拓扑：单网口旁路由模式（最稳定、不影响主网络）
* **主路由**（如硬路由/光猫）：负责拨号上网、开启 DHCP、分配 IP（假设 IP 为 `192.168.1.1`）。
* **旁路由**（OpenWrt 迷你主机）：接在主路由的 LAN 口上，分配静态内网 IP（如 `192.168.1.2`）。
* **优势**：即使软路由宕机或重启，主路由网络依然正常，家人的手机、电脑上网不受任何影响。

## 二、OpenWrt 旁路由基础网络设置（关键防死机）

进入 OpenWrt 后台（网络 - 接口 - LAN 口）：

1. **基本设置**：
   - IPv4 地址：设为与主路由同网段的静态 IP，例如 `192.168.1.2`。
   - 子网掩码：`255.255.255.0`。
   - **IPv4 网关**：必须填入 **主路由的 IP**（`192.168.1.1`）。
   - **DNS 服务器**：必须填入主路由 IP（`192.168.1.1`）或公共 DNS（`223.5.5.5`）。
2. **高级设置**：
   - 勾选 **「忽略此接口（不在此接口提供 DHCP 服务）」**（由主路由统一发 IP，避免局域网 DHCP 冲突）。
3. **防火墙设置**：
   - 切换到「网络 - 防火墙 - 自定义规则」，添加一条 iptables 转发伪装规则（部分新版固件只需勾选 LAN 口的「IP 动态伪装 (Masquerading)」即可）：
     ```bash
     iptables -t nat -I POSTROUTING -o eth0 -j MASQUERADE
     ```

## 三、部署代理插件（PassWall / OpenClash）

在 iStore 商店或软件包中安装 **PassWall** 或 **OpenClash**：

1. **导入节点订阅**：
   - 进入节点列表，粘贴在 [首页 2026 稳定机场推荐总榜](/#ranking) 获取的 V2Ray / Clash 订阅链接，点击更新。
2. **DNS 智能防污染设置**：
   - 国内 DNS：选用 `119.29.29.29` 或 `223.5.5.5`。
   - 远程过滤 DNS：选用 `1.1.1.1` 或 `8.8.8.8`（经代理查询）。
3. **分流模式选择**：
   - 推荐选择 **中国列表以外 (China-List-Out)** 或 **GFW 列表模式**，确保局域网设备访问国内站点零损耗直连。

## 四、终端设备如何接入旁路由？

你不需要改动全家人的手机！如果只需要让 Apple TV 或特定办公电脑走代理：
1. 打开 Apple TV 的「网络设置」，将 IP 设置从自动改为 **手动**。
2. IP 地址：保持不变（如 `192.168.1.50`）。
3. **路由器（网关）**：修改为旁路由 IP（**`192.168.1.2`**）。
4. **DNS**：修改为旁路由 IP（**`192.168.1.2`**）。
5. 保存后，Apple TV 即可秒开 4K Netflix、YouTube 与 Disney+，彻底免去安装任何客户端的繁琐步骤。
