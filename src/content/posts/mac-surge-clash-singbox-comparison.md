### 1. 系统流量接管能力：增强模式 vs Tun 网卡
- **Surge 5（增强模式 Enhanced Mode）**：Surge 在 macOS 上开发了专门的内核级系统网络驱动（Network Extension），其增强模式能够百分之百接管包括终端 `curl`、`git`、Docker 容器以及系统原生服务在内的所有 TCP/UDP 流量，完全不会出现普通代理工具中“命令行漏跑直连”的尴尬。
- **Clash Verge Rev**：依托开源 Clash Meta 内核的 Tun 虚拟网卡驱动，支持全局系统虚拟网络分流。详细安装与配置步骤可参考站内的 [2026 最新 Clash Verge Rev 客户端配置指南](/posts/clash-verge-tutorial/)。
- **Sing-box**：基于自主研发的架构提供原生 Tun 接口，对新一代协议支持极为激进。具体配置请参考 [Sing-box 全平台通用配置指南与订阅转换实战](/posts/sing-box-full-guide/)。

## 二、Surge 5 独门神技与生产力实战

如果你预算充足或已购置了 Surge Mac 授权，以下三大核心功能是其他免费工具无法比拟的：

### 1. 终端与进程级精准分流 (Process Name Routing)
Surge 允许基于 macOS 应用程序进程名（Process Name）编写精细规则：
```ini
[Rule]
# 针对特定出海办公工具走专用原生专线
PROCESS-NAME,Slack,Proxy
PROCESS-NAME,zoom.us,DIRECT
PROCESS-NAME,Cursor,GPT-Unlock
FINAL,DIRECT
```
无论工具内部使用何种冷门协议或非标准端口，Surge 都能通过系统 API 识别发起请求的执行文件，避免全局翻墙导致微信文件传输被阻断。

### 2. 本地 HTTP/HTTPS MitM 抓包解密与脚本重写
前端与移动端开发者无需再单独开启 Charles 或 Fiddler，Surge 内置了完整的请求审计面板，支持直接查看 HTTPS 请求体、Mock 数据注入以及针对特定 API 编写 JavaScript 脚本实时修改返回内容。

### 3. PONTE 远程家庭局域网穿透
结合 iCloud 密钥交换，Surge 可以在你的 Mac 与家中常开的 Mac mini 之间建立基于 WireGuard 协议的安全点对点隧道，即使在外出星巴克办公时，也能以秒级速度直接访问家中 NAS 共享文件夹。

## 三、MacBook 续航调优：告别后台发热发烫

很多用户抱怨运行代理工具后，MacBook 电池续航从 12 小时暴跌至 5 小时。想要实现“冰凉省电”，只需落实以下三项调优：

1. **关闭节点自动定时批量测速**：
   - 很多订阅默认开启了 `interval: 300`（每 5 分钟并发 Ping 上百个节点），这会强制唤醒 Mac 的 Wi-Fi 芯片与 CPU 高频核心。建议将其调整为手动测速或将间隔增大至 `1800` 秒。
2. **启用 Fake-IP 模式减少 DNS 唤醒**：
   - 传统 Redir-Host 模式下，每次访问域名都会在本地向远端发起 DNS 握手；Fake-IP 能够直接返回虚假内网地址（如 `198.18.x.x`），真正解析交由高速专线远端完成，极大节省无线电收发能耗。
3. **搭配高稳定性内网专线**：
   - 频繁的公网丢包会导致代理客户端在底层不断重发 TCP 数据包，加重 CPU 计算负载。建议优先在 [首页 2026 稳定机场推荐总榜](/#ranking) 中挑选延迟稳定、抗抖动的优质内网专线。底层原理详见 [IPLC 专线 vs BGP 隧道中转对比](/posts/iplc-vs-bgp-transit-differences/)。
